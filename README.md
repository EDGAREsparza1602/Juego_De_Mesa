# CLUE-LITE (5 casos)
Pequeño simulador de Clue en consola con 5 historias/ﬁnales cerrados.

## Ejecutar
```bash
python main.py
```

## Comandos
- `lista` — muestra sospechosos, locaciones y armas
- `sugerir` — introduces una terna y recibes una pista contextual
- `acusar` — introduces una terna y, si aciertas, ves el final del caso
- `pistas` — lista pistas reveladas
- `ayuda` — muestra la ayuda
- `salir` — termina la partida

## Publicación
- **GitHub**: crea un repo y sube `main.py`, `README.md`, `LICENSE`, `flowchart.png` y el PDF `7E_22110308_PracticaX.pdf`.
- **itch.io**: crea un proyecto tipo *Downloadable* y sube el `.zip` que se adjunta en este paquete.
